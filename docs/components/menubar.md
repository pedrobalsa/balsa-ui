# Menubar

Menubar renders persistent top-level application menus with horizontal roving focus and the same typed menu items used by Dropdown and Context Menu. Left/Right/Home/End navigate triggers; opening transfers across adjacent menus; menu selection and Escape restore the active trigger. Install with `npx balsa-ui@latest add menubar`.

Canonical source: `src/components/ui/Menubar.vue`; interactive documentation: `/docs/components/menubar`; contract: `specs/components/menubar.json`.
