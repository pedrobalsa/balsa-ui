# Tooltip

Tooltip describes a focusable element with compact supplementary content after pointer hover or keyboard focus. It is non-interactive, collision-aware, and supports portal or contained rendering; use Hover Card for richer previews and Popup for interactive content. Install with `npx balsa-ui@latest add tooltip`.

Canonical source: `src/components/ui/Tooltip.vue`; interactive documentation: `/docs/components/tooltip`; contract: `specs/components/tooltip.json`.
