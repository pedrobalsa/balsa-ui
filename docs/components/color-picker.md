# ColorPicker

ColorPicker exposes `outline`, `surface` (default), `soft`, and `glass` variants for its trigger and color-code editor controls.

Use Tailwind-style `rounded` values from `none` through `full` for a standalone field trigger; contiguous `palette` segments intentionally keep their shared geometry.

Use ColorPicker when a user needs to choose a six-digit hex color. The default `type="field"` treatment keeps its concise label outside a compact filled square, left aligned and never truncated; a long label can extend naturally without stretching the square itself. Set `label-position="inside"` to center the label inside that same square; its foreground automatically resolves to black or white for contrast against the selected color. Field sizes are `sm` (32px), `md` (40px, default), and `lg` (56px). Use `type="palette"` for a full-width filled rectangle with a screen-reader label, allowing several pickers to form one contiguous palette strip. Activating either type opens a Balsa-owned top-layer popover that is positioned before it fades in, with separate saturation/brightness and hue controls, live updates, and a compact format Select beside an editable color-code field. Choose HEX, RGB, or HSL; the public model remains a normalized six-digit hex string. Incomplete or invalid text stays editable while typing and restores the last valid value only on Blur. Dragging the saturation/brightness field preserves the selected hue, including at black, white, and gray edges. The optional `actions` slot renders contextual actions immediately before Close and receives a `close` callback for workflows such as removing a palette color before focusing its neighbor. The saturation field supports arrow keys, the hue uses native range semantics, Escape closes and restores focus, and invalid color-code text receives explicit feedback. Provide a unique `id` and `label`; use `accessibleLabel` when the concise label needs a fuller accessible name. Install with `npx balsa-ui@latest add color-picker`. Dependencies: Vue, Balsa Button, Input, Select, and the Balsa theme foundation. Canonical source: `src/components/ui/ColorPicker.vue`; interactive documentation: `/docs/components/color-picker`; contract: `specs/components/color-picker.json`.

ColorPicker inherits the nearest `data-theme` and accepts `theme?: ThemeInput`; its top-layer editor keeps the same override.
