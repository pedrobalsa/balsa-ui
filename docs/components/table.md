# Table

Table preserves consumer-authored semantic table markup inside a responsive Balsa surface. It adds typed material, density, independently configurable semantic header and row colors, stripes, hover, gridlines, sticky headers, geometry, and valid loading or empty rows without hiding native caption and header relationships.

Header scope and alignment stay explicit in consumer-authored `th` and `td` markup. Use Table for static semantic comparison data, use DataTable for sorting/filtering/pagination/selection, and never use either primitive as a page-layout grid.

Install with `npx balsa-ui@latest add table`. Canonical source: `src/components/ui/Table.vue`; interactive documentation: `/docs/components/table`; contract: `specs/components/table.json`.
