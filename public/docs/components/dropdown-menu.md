# Dropdown Menu

Dropdown Menu presents typed actions, labels, separators, checkbox/radio state, shortcuts, destructive items, and one-level submenus from a native button. It supports semantic `color` and `rounded` panel geometry. The shared menu engine provides roving focus, Arrow/Home/End keys, typeahead, collision-safe portal positioning, Escape/outside dismissal, and focus restoration. Install with `npx balsa-ui@latest add dropdown-menu`.

Canonical source: `src/components/ui/DropdownMenu.vue`; interactive documentation: `/docs/components/dropdown-menu`; contract: `specs/components/dropdown-menu.json`.
