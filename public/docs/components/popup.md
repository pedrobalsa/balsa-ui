# Popup

Popup renders interactive rich content beside a native button trigger with controlled state, focus entry and restoration, Escape/outside dismissal, collision flipping, four sides, three alignments, portal escape, contained previews, and inherited theme/palette context. Composed fields can attach their visible label, description, required state, and invalid state directly to the owned trigger. Install with `npx balsa-ui@latest add popup`.

Canonical source: `src/components/ui/Popup.vue`; interactive documentation: `/docs/components/popup`; contract: `specs/components/popup.json`.
