# Hover Card

Hover Card previews supplementary content after cancellable pointer-hover or keyboard-focus delays. It never transfers focus, remains open across the pointer gap, collision-flips inside the viewport, and supports portal or contained rendering. Essential actions belong in Popup instead. Install with `npx balsa-ui@latest add hover-card`.

Canonical source: `src/components/ui/HoverCard.vue`; interactive documentation: `/docs/components/hover-card`; contract: `specs/components/hover-card.json`.
