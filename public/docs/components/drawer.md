# Drawer

Drawer presents a native modal dialog from any viewport edge with typed extents, scrollable content, optional handle drag dismissal, deliberate Escape/backdrop policy, focus trapping/restoration, page-scroll locking, contained previews, and complete theme/palette inheritance. Install with `npx balsa-ui@latest add drawer`.

Canonical source: `src/components/ui/Drawer.vue`; interactive documentation: `/docs/components/drawer`; contract: `specs/components/drawer.json`.
