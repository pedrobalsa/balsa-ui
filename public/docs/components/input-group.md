# Input Group

Input Group connects typed text or icon addons and optional Balsa actions to one labelled native text control. It retains the established shared form surface, focus, required, disabled, loading, validated, and unvalidated behavior without introducing another form variant or color API.

Inline layout connects short start/end content beside the input. Stacked layout moves addon content above and below the control for longer labels or narrow screens. The input remains first in DOM focus order even when start content is displayed before it. Install with `npx balsa-ui@latest add input-group`.

Canonical source: `src/components/ui/InputGroup.vue`; interactive documentation: `/docs/components/input-group`; contract: `specs/components/input-group.json`.
