# Calendar

Calendar provides locale-aware single, multiple, and range date-only selection with one or two months, disabled-date rules, fixed weeks, outside days, and complete grid keyboard navigation. Arrow keys move by day or week, Home and End move within a week, and PageUp/PageDown preserve the day across month or year movement when possible.

Use Calendar for an always-visible date grid. Use DatePicker when the grid should open from a compact field, and avoid Calendar for time selection, ambiguous free-text parsing, or timezone scheduling.

Install with `npx balsa-ui@latest add calendar`. Canonical source: `src/components/ui/Calendar.vue`; interactive documentation: `/docs/components/calendar`; contract: `specs/components/calendar.json`.
