# Command Menu

Command Menu filters grouped typed commands with case- and diacritic-insensitive matching, combobox/listbox active-descendant semantics, Arrow/Home/End navigation, Enter selection, loading and empty states, an inline query with an anchored dropdown or on-demand dialog presentation, configurable small/medium/large scale, and an optional platform command hotkey. Install with `npx balsa-ui@latest add command-menu`.

Canonical source: `src/components/ui/CommandMenu.vue`; interactive documentation: `/docs/components/command-menu`; contract: `specs/components/command-menu.json`.
