# Contributing

Thanks for improving Balsa UI.

1. Open an issue for substantial API or behavior changes.
2. Read `AGENTS.md`, the compact catalog, the selected component specification, and canonical source.
3. Change canonical source only; generation updates registry, hosted, starter, and fixture mirrors.
4. Add focused behavior and accessibility coverage.
5. Run `npm run check:changed`; run `npm run check` for distribution changes.
